# 🃏 Розробка логічної карткової гри (CardGame101)

Курсова робота з дисципліни «Основи програмування»

КПІ ім. Ігоря Сікорського · 2026

Програмний продукт реалізує логічну карткову гру з покроковою механікою та збереженням стану, використовуючи графічний інтерфейс на базі .NET Windows Forms.

---

##  Основні характеристики

| Компонент | Технологія / Формат | Особливості |
| :--- | :--- | :--- |
| Платформа | .NET (C#) | Базується на принципах ООП |
| Інтерфейс | Windows Forms | Динамічне оновлення елементів UI |
| Збереження даних | JSON (save.json) | Серіалізація/десеріалізація об'єктів гри |

---

##  Вимоги до системи

Оскільки додаток використовує віконний інтерфейс Windows Forms, він підтримується виключно на операційній системі Windows.

| Компонент | Мінімальна версія |
| :--- | :--- |
| Операційна система | Windows 10 або новіша |
| Середовище виконання | .NET Desktop Runtime 8.0+ (або SDK) |
| Середовище розробки (опціонально) | Visual Studio 2022 або VS Code |

---

##  Збірка та запуск

Проєкт автоматично підтягує всі стандартні залежності .NET під час першої збірки, тому додаткове встановлення зовнішніх пакетів (NuGet) не вимагається.

### Клонування репозиторію

```bash
git clone [https://github.com/mityagitthebest15/KursovaC-.git](https://github.com/mityagitthebest15/KursovaC-.git)
cd KursovaC-

Запуск через термінал (VS Code / .NET CLI)
Перейдіть у директорію з вихідним кодом та виконайте команду запуску:
cd CardGame101
dotnet run

Запуск через Visual Studio
Відкрийте файл рішення KursovaC#.sln.
Натисніть F5 або кнопку Start на верхній панелі інструментів.

 ## Структура проєкту
KursovaC-/
├── KursovaC#.sln          # Головний файл рішення (Solution)
└── CardGame101/           # Директорія вихідного коду
    ├── Program.cs         # Точка входу в програму
    ├── Form1.cs           # Графічний інтерфейс (головне вікно гри)
    ├── Form1.Designer.cs  # Автозгенерований код компонування UI
    ├── GameEngine.cs      # Логічне ядро гри (обробка ходів, правил)
    ├── Models/            # Класи моделей даних (наприклад, Card)
    └── bin/Debug/         # Директорія зібраних виконуваних файлів
        ├── CardGame101.exe
        └── save.json      # Файл збереження прогресу (генерується під час гри)

🎮 Функціонал
Ігровий процес
Генерація ігрової колоди та роздача початкових карт.
Взаємодія гравця з системою через графічні кнопки та зображення.
Автоматичний підрахунок очок на основі закладених математичних алгоритмів.
Визначення переможця по завершенню карт у колоді або при досягненні ліміту.
Захист від некоректних дій користувача (блокування ходів після кінця гри).
Робота з даними (Збереження та Завантаження)
Збереження: При натисканні кнопки «Зберегти» стан ігрового поля, поточний рахунок та залишок карт серіалізуються та записуються у локальний файл save.json.
Завантаження: Програма зчитує файл конфігурації, десеріалізує дані та повністю відновлює ігрову сесію, дозволяючи продовжити гру після перезапуску програми.
